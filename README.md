# WindowsAppPacker

Десктопное GUI-приложение для упаковки Python-скриптов в standalone `.exe`.
Работает как удобная графическая обёртка над [PyInstaller](https://pyinstaller.org/).

## Возможности

- Выбор исходного `.py` файла (в том числе перетаскиванием, если установлен `tkinterdnd2`).
- Кастомное имя итогового EXE и выбор `.ico` иконки.
- Тип сборки: **Onefile** (один exe) или **Onedir** (папка с зависимостями).
- Скрытие консольного окна для GUI-приложений.
- Добавление дополнительных файлов/папок (данные, картинки, json, csv и т.д.), упаковываемых вместе со скриптом.
- Метаданные EXE: версия, описание, автор/компания, имя продукта — отображаются в свойствах файла в Windows.
- Флаг «Требовать права администратора» (UAC-манифест).
- Пресеты: сохранение и загрузка наборов настроек сборки.
- Лог сборки в реальном времени и индикатор прогресса.

## Установка

```bash
pip install -r requirements.txt
```

Для поддержки drag-and-drop дополнительно установите:

```bash
pip install tkinterdnd2
```

## Запуск

```bash
python WindowsAppPacker.py
```

## Использование

1. На вкладке **Основное** выберите `.py` скрипт, задайте имя EXE, при желании — иконку и папку вывода.
2. На вкладке **Доп. файлы** добавьте файлы/папки, которые нужно упаковать вместе со скриптом.
3. На вкладке **Метаданные** укажите версию, описание, автора — это попадёт в свойства EXE (актуально при сборке на Windows).
4. На вкладке **Дополнительно** при необходимости добавьте произвольные аргументы PyInstaller.
5. Нажмите **«Собрать EXE»**. Прогресс и лог сборки отображаются внизу окна. Собранный файл появится в указанной папке вывода (по умолчанию `dist/`).

Настройки можно сохранить как именованный пресет и повторно загрузить его в следующий раз.

## Примечания

- Встраивание версии/автора/описания в свойства EXE (`--version-file`) — это ресурс формата Windows PE, поэтому сборку с этими метаданными нужно выполнять на Windows (или под Wine).
- Приложение вызывает PyInstaller через `python -m PyInstaller`, поэтому PyInstaller должен быть установлен в том же окружении Python, что и WindowsAppPacker.

## Структура проекта

Весь проект — один файл `WindowsAppPacker.py`: модель настроек сборки,
построение команды PyInstaller и запуск сборки в отдельном потоке,
генерация файла версии, пресеты и весь GUI на CustomTkinter.
