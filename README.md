# WindowsAppPacker

Десктопное GUI-приложение для упаковки Python-скриптов в standalone `.exe`.
Работает как удобная графическая обёртка над [PyInstaller](https://pyinstaller.org/).

## Возможности

- Выбор исходного `.py` файла (в том числе перетаскиванием, если установлен `tkinterdnd2`).
- Кастомное имя итогового EXE и выбор `.ico` иконки.
- Папка вывода — пустая по умолчанию, подтягивается из папки скрипта.
- Скрытие консольного окна для GUI-приложений.
- Флаг «Запуск от имени администратора» (UAC-манифест).
- Кнопка «Очистить» сбрасывает поля блока «Основное» к значениям по умолчанию.
- Одна кнопка переключения светлой/тёмной темы в правом верхнем углу окна.
- Панель журнала открыта по умолчанию и сворачивается кнопкой-стрелкой в её шапке, с индикатором прогресса и процентом сборки, и коротким итоговым сообщением об успехе/ошибке.

Сборка всегда собирается в один EXE (Onefile).

## Установка

```bash
pip install -r requirements.txt
```

Для поддержки drag-and-drop дополнительно установите:

```bash
pip install tkinterdnd2
```

## Запуск

```bash
python WindowsAppPacker.py
```

## Использование

1. В блоке **«Основное»** выберите `.py` скрипт, задайте имя EXE, при желании — иконку, папку вывода и флаги.
2. Нажмите **«Собрать EXE»**. Прогресс и лог сборки отображаются внизу окна. Собранный файл появится в указанной папке вывода (если её не указать — в `dist/` рядом со скриптом сборщика).

## Примечания

- Приложение вызывает PyInstaller через `python -m PyInstaller`, поэтому PyInstaller должен быть установлен в том же окружении Python, что и WindowsAppPacker.
- Собранный `WindowsAppPacker.exe` не может сам собирать другие EXE — для сборки нужно запускать `WindowsAppPacker.py` напрямую через Python с установленным PyInstaller.

## Структура проекта

Весь проект — один файл `WindowsAppPacker.py`: модель настроек сборки,
построение команды PyInstaller, запуск сборки в отдельном потоке и весь
GUI на CustomTkinter.

`app_icon.ico` — готовая иконка приложения (та же, что встроена в окно
программы). Пригодится, если упаковывать сам `WindowsAppPacker.py` в
EXE: можно указать этот файл в поле «Иконка (.ico)».
