# WindowsAppPacker

Десктопное GUI-приложение для упаковки Python-скриптов в standalone `.exe`.
Работает как удобная графическая обёртка над [PyInstaller](https://pyinstaller.org/).

## Возможности

- Выбор исходного `.py` файла (в том числе перетаскиванием, если установлен `tkinterdnd2`).
- Кастомное имя итогового EXE и выбор `.ico` иконки.
- Папка вывода — пустая по умолчанию, подтягивается из папки скрипта.
- Скрытие консольного окна для GUI-приложений.
- Метаданные EXE: версия (с маской ввода «только цифры и точки», запятая автоматически заменяется на точку), описание, автор/компания, имя продукта — отображаются в свойствах файла в Windows.
- Флаг «Запуск от имени администратора» (UAC-манифест).
- У каждого блока своя кнопка «Очистить» — сбрасывает поля только этого блока.
- Переключатель светлой/тёмной темы в правом верхнем углу окна.
- Панель журнала всегда видна, с индикатором прогресса и процентом сборки, и коротким итоговым сообщением об успехе/ошибке.

Сборка всегда собирается в один EXE (Onefile).

## Установка

```bash
pip install -r requirements.txt
```

Для поддержки drag-and-drop дополнительно установите:

```bash
pip install tkinterdnd2
```

## Запуск

```bash
python WindowsAppPacker.py
```

## Использование

1. В блоке **«Основное»** выберите `.py` скрипт, задайте имя EXE, при желании — иконку, папку вывода и флаги.
2. В блоке **«Метаданные»** укажите версию, описание, автора — это попадёт в свойства EXE (актуально при сборке на Windows).
3. Нажмите **«Собрать EXE»**. Прогресс и лог сборки отображаются внизу окна. Собранный файл появится в указанной папке вывода (если её не указать — в `dist/` рядом со скриптом сборщика).

## Примечания

- Встраивание версии/автора/описания в свойства EXE (`--version-file`) — это ресурс формата Windows PE, поэтому сборку с этими метаданными нужно выполнять на Windows (или под Wine).
- Приложение вызывает PyInstaller через `python -m PyInstaller`, поэтому PyInstaller должен быть установлен в том же окружении Python, что и WindowsAppPacker.

## Структура проекта

Весь проект — один файл `WindowsAppPacker.py`: модель настроек сборки,
построение команды PyInstaller и запуск сборки в отдельном потоке,
генерация файла версии и весь GUI на CustomTkinter.
